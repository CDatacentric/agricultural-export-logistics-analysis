## Project Overview

This project analyzes agricultural export and logistics transactions to evaluate the company's financial performance, operational efficiency, product and market performance, supplier contribution, and customer experience.

The project began with a dataset containing 5,051 records across 30 fields. I used Microsoft Excel and Power Query to structure, clean, validate, and transform the data before creating calculated analytical fields and using PivotTables to explore the dataset from multiple business perspectives.

The analysis culminated in an interactive executive dashboard that brings key financial and operational indicators together while allowing users to investigate performance by year, quarter, product, country, supplier, and shipping method.

The project also documents the analytical decisions made during data preparation, including the validation of financial calculations and the investigation and treatment of 152 missing Shipping Cost values.
